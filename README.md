# CareerFoundry Python Course – Achievement 1

This repository documents my work and progression through **Achievement 1** of the CareerFoundry Software Engineering Program.  
It covers core Python fundamentals, object-oriented programming, database integration with MySQL, and building a fully functional command-line application using SQLAlchemy (ORM).

---

## Overview

Throughout Achievement 1, I developed a **command-line Recipe application** that evolved across multiple stages:

1. Core Python fundamentals  
2. File handling and data persistence  
3. Object-Oriented Programming (OOP)  
4. MySQL database integration  
5. ORM-based database interaction using SQLAlchemy  
6. Final production-ready CLI application with full CRUD functionality  

The final application allows users to:

- Create recipes
- View all recipes
- Search recipes by ingredients
- Edit existing recipes
- Delete recipes
- Persist data in a MySQL database using SQLAlchemy ORM

---

## Repository Structure

Each exercise is organized in its own folder:

### **Exercise 1.1 – Getting Started with Python**
- Virtual environments (`venv`)
- pip and dependency management
- IPython
- Project setup and environment configuration

### **Exercise 1.2 – Data Types in Python**
- Variables and built-in data types
- Lists, tuples, dictionaries
- Designing data structures for a Recipe app

### **Exercise 1.3 – Functions and Program Flow**
- Conditional statements
- Loops
- Writing reusable functions
- Input handling and simple CLI logic

### **Exercise 1.4 – File Handling**
- Reading and writing files
- Pickling Python objects
- Persisting Recipe data locally (`recipes.bin`)
- Error handling using `try`/`except`

### **Exercise 1.5 – Object-Oriented Programming**
- Building a `Recipe` class
- Data and procedural attributes
- Custom methods
- Inheritance, polymorphism, operator overloading
- Searching recipes using object methods
- `recipe_oop.py`

### **Exercise 1.6 – Connecting to Databases**
- Installing and configuring MySQL
- Creating users and managing permissions
- Creating databases and tables
- Executing SQL queries through Python
- Performing CRUD operations using `mysql-connector-python`

### **Exercise 1.7 – SQLAlchemy & Final Application**
- Introduction to Object Relational Mapping (ORM)
- Connecting SQLAlchemy to MySQL
- Defining declarative models
- Mapping Python classes to database tables
- Using sessions to manage transactions
- Filtering, updating, and deleting records using ORM methods
- Building the final production CLI application:
  - `recipe_app.py`
  - Full menu-driven interface
  - Input validation
  - Ingredient-based search using dynamic filters
  - Automatic difficulty calculation
  - Robust error handling
  - Clean session and engine shutdown
